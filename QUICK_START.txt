OptiWMS Quick Start
===================

Run services in this order:
1. PostgreSQL
2. Spring Boot backend
3. Next.js frontend
4. Optional FastAPI AI agent

Prerequisites
-------------
- Docker
- Java 21
- Node.js 18+
- npm
- Python 3.11+ recommended

Option A: Use helper scripts
----------------------------
From the repo root:

1. Start PostgreSQL
   powershell -ExecutionPolicy Bypass -File .\scripts\start-db.ps1

2. Start backend
   powershell -ExecutionPolicy Bypass -File .\scripts\start-backend.ps1

   If rack seeding causes startup issues:
   powershell -ExecutionPolicy Bypass -File .\scripts\start-backend.ps1 -DisableRackSeed

3. Start frontend
   powershell -ExecutionPolicy Bypass -File .\scripts\start-frontend.ps1

4. Optional: start AI agent
   powershell -ExecutionPolicy Bypass -File .\scripts\start-ai-agent.ps1

Option B: Run commands manually
-------------------------------
1. Start the database
   docker compose -f infra/docker-compose.yml up -d db

2. Start the backend
   cd backend
   .\gradlew.bat :core-api:bootRun

3. Start the frontend
   cd frontend
   npm install
   npm run dev

4. Optional: start the AI agent
   cd ai-services\ai-agent
   python -m venv .venv
   .venv\Scripts\Activate.ps1
   pip install -r requirements.txt
   uvicorn api:app --reload --host 0.0.0.0 --port 8000

Local URLs
----------
- Frontend: http://localhost:3000
- Backend: http://localhost:8080
- Backend health: http://localhost:8080/actuator/health
- AI agent: http://localhost:8000
- AI health: http://localhost:8000/health
