## 🆘 IF SOMETHING FAILS

### Backend (Java) Issues:
1. Check file exists at correct path
2. View file content: `cat [filepath]`
3. Look for syntax errors
4. Compile: `cd backend && ./gradlew compileJava`
5. Read error message carefully

### Frontend (React) Issues:
1. Check browser console: F12 → Console tab
2. Look for red error messages
3. Hard refresh: Ctrl+F5
4. Clear browser cache
5. Restart dev server
6. Check imports in file
